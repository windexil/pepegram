## БЕТ 1. Концепция, проблемалық жағдай, аудитория, оқу нәтижелері

### 1.1. Проблемалық жағдай
Оқушылар тарихи ақпаратты көбіне дайын «факт» ретінде қабылдайды, ал әлеуметтік желілерде тарих туралы
жалған «архив құжаттары», контекстен тыс фотолар, мерейтойлық асыра сілтеулер кең тарайды. Мектеп
тапсырмаларында дереккөзді сыни бағалау («кім, қашан, не үшін жазды?») жиі тест сұрағына айналып кетеді.
**Мәселе:** оқушыда дереккөз сенімділігін бағалау, хронологиялық ойлау және дәлелге негізделген қорытынды
жасау дағдыларын біріктіріп жаттықтыратын интерактивті орта жоқ.

### 1.2. Ойын идеясы
Ойыншы — тарихи дерек детективі. Әр «іс» — бір тарихи эпизод: мұрағатқа бір-біріне қайшы келетін үш дереккөз
түседі. Ойыншы оларды зерттейді, салыстырады, оқиғалар мен дереккөздерден уақыт осін қалпына келтіріп,
анахронизмдерді табады, әр дереккөздің сенімділігін бағалайды және зерттеу сұрағына **тек сенімді дәлелдерге
сүйеніп** жауап береді. Жүйе әр қадамды тексеріп, педагогикалық түсіндірме береді.

**Бір сөйлеммен:** «Тест емес, тергеу: тарихты дереккөз арқылы зерттеп, фейкті дәлелмен әшкерелейтін детективтік ойын».

### 1.3. Мақсатты аудитория
- **Негізгі:** 8–11 сынып оқушылары (13–17 жас), «Қазақстан тарихы» және медиасауаттылық сабақтары.
- **Қосымша:** колледждің 1-курс студенттері; тарих пәні мұғалімдері (сабақта 25–35 минуттық белсенді тапсырма ретінде).
- **Ойыншы профилі:** смартфон/ДК қолданады, әлеуметтік желіде тарихи контентпен кездеседі, дереккөз талдауында тәжірибесі аз.
- **Сессия ұзақтығы:** бір іс 7–12 минут; толық ойын (3 іс) 25–40 минут.

### 1.4. Оқу нәтижелері (ойыннан кейін оқушы…)
| Код | Оқу нәтижесі | Ойындағы тексерілу орны | Блум деңгейі |
|---|---|---|---|
| ОН1 | Бастапқы және екінші реттік дереккөзді, ресми құжатты, естелікті, медиа материалды ажыратады | Карточка деректемелері, белгі таңдау | Түсіну |
| ОН2 | Автордың мүддесін, біржақтылықты және бағалауыш сөздерді анықтайды | Қызыл белгілер, «біржақтылық» белгісі | Талдау |
| ОН3 | Оқиғаларды хронологиялық ретпен орналастырады, жанама уақыт маркерлерін («кеше», апта күні) пайдаланады | Хронология тақтасы | Қолдану |
| ОН4 | Анахронизмді және уақыттық сәйкессіздікті табады | ⚠ белгісі, қызыл белгілер | Талдау |
| ОН5 | Дереккөз сенімділігін 1–5 шкаласы бойынша негіздеп бағалайды | Сенімділік кезеңі | Бағалау |
| ОН6 | Зерттеу сұрағына дәлелге негізделген қорытынды жасайды, сенімсіз дереккөзге сүйенбейді | Қорытынды кезеңі | Синтез / Бағалау |
| ОН7 | Вирустық фейктің белгілерін (эмоциялық қысым, провенанс жоқ, тексерілмейтін сілтеме) таниды | 2-, 3-істегі посттар | Талдау |

## БЕТ 2. Негізгі ойын циклі, кезеңдер, жеңіс шарты

### 2.1. Core Loop
```
 ┌─► Іс таңдау ─► Брифинг (зерттеу сұрағы, бейімделу баптаулары)
 │       │
 │       ▼
 │   1. ЗЕРТТЕУ: 3 карточканы ашу → деректемелер → сөйлемдерді белгілеу → «Салыстыру» режимі
 │       ▼  (кері байланыс: табылған/байқалмаған айғақтар + түсіндірме)
 │   2. ХРОНОЛОГИЯ: ▲/▼ реттеу → ⚠ сәйкессіздік → Тексеру (≤3 рет) → қате элемент астында түсіндірме
 │       ▼
 │   3. СЕНІМДІЛІК: 1–5 шкала + бұрмалану түрі → Тексеру → сарапшы түсіндірмесі
 │       ▼
 │   4. ҚОРЫТЫНДЫ: нұсқа + дәлелдер → дәлелділік тексерісі (0–100)
 │       ▼
 │   НӘТИЖЕ: ұпай құрылымы, жұлдыз, өту/өтпеу, статистика, БЕЙІМДЕЛУ ШЕШІМІ
 └──────── Келесі іс / Қайта ойнау / Аналитика
```

### 2.2. Кезеңдер механикасы
| Кезең | Ойыншы әрекеті | Тексеру | Максимум ұпай |
|---|---|---|---|
| 1. Зерттеу | Әр сөйлемді басу арқылы маңызды/күдікті фрагменттерді белгілеу; 2 карточканы қатар салыстыру | табылған/маңызды − артық/бейтарап | 100 |
| 2. Хронология | 8–9 элементті реттеу, анахронизмдерді белгілеу | Spearman ауытқуы (кездейсоқ рет = 0) + сәйкессіздік | 300 |
| 3. Сенімділік | Әр карточкаға 1–5 және белгі (6 түрден) | шкала жақындығы (60) + белгі (40) әр карточкаға | 300 |
| 4. Қорытынды | 3–4 нұсқадан біреуі + дәлелдер (карточкалар, расталған оқиғалар) | дәлелділік баллы × 3 | 300 |
| Бонус | Дұрыс әрі дәлелді қорытынды тез жасалса | уақыт / мақсатты уақыт | +100 |
| Айыппұл | Кеңес алу | 25…10 (кеңес деңгейіне тәуелді) | − |

### 2.3. Деңгейлер (3 кезең/деңгей) және жеңіс шарты
- 3 іс біртіндеп ашылады: 2-іс 1-іс шешілгенде, 3-іс 2-іс шешілгенде ашылады.
- **Істі шешу шарты:** қорытынды дұрыс **және** жалпы нәтиже ≥ 45 %.
- **Ойынның жеңіс шарты:** үш іс те шешілді → «Бас детектив» атағы (нәтиже экраны мен іс папкаларында көрсетіледі).
- Жұлдыздар: ≥85 % ★★★, ≥65 % ★★, ≥45 % ★.
- Істі кез келген уақытта қайта ойнауға болады (үздік нәтиже сақталады).

### 3.3. Хронология элементтері
Әр істе 8–9 элемент: 5–6 тарихи оқиға + 3 дереккөз (жасалған немесе мәлімделген күні бойынша).
Сәйкессіздіктер: 1-іс — жалған жарлық; 2-іс — естелік (жад қатесі) және пост (анахронизм); 3-іс — «архив құжаты».
Расталған оқиғалардың кейбірі қорытынды кезеңінде **дәлел** ретінде қолданылады (1465 ж., 25.06.1916 жарлығы, Торғай қоршауы, 16.12.1986 пленумы, 1989–1990 комиссиясы).

## БЕТ 4. UI/UX және экрандар

### 4.1. Визуалды стиль
«Детектив кабинеті»: қою қоңыр «үстел» фоны (`#17140f`), сарғыш «іс қағазы» карточкалары (`#efe4c8`),

### 4.3. Кері байланыс қағидалары
1. Әр тексерістен кейін — **не дұрыс, не қате, неге** (тек «қате» деп айтылмайды).
2. Қате орналасқан хронология элементінің астында дұрыс орны және себебі жазылады; 2 тексерістен кейін «Дұрыс ретті көрсету» ашылады.
3. Сенімділік кезеңінде ойыншы бағасы мен сарапшы бағасы қатар көрсетіледі.
4. Қорытындыда: қолданылмаған міндетті дәлел, жалған дереккөз (−30), өзіндік қайшылық (−10) жеке аталады.

## БЕТ 5. Педагогикалық модель

### 5.1. Әдістемелік негіз
- **Тарихи ойлау дағдылары:** дереккөзді анықтау (sourcing), контекстке қою (contextualization), айқас тексеру (corroboration), мұқият оқу (close reading).
- **Медиасауаттылық:** «5 сұрақ» әдісі (Кім? Қашан? Қайда сақталды? Не үшін? Кім растайды?), латерал оқу, провенанс, эмоциялық манипуляция белгілері.
- **Блум таксономиясы:** түсіну (карточка түрі) → қолдану (хронология) → талдау (белгілер, анахронизм) → бағалау (сенімділік) → синтез (қорытынды).
- **Конструктивистік оқыту:** ойыншы білімді дайын түрде алмайды — гипотеза құрып, тексеріп, түзетеді (хронологияны 3 рет тексеру мүмкіндігі).

### 5.2. Педагогикалық дұрыстық кепілдері
| Қағида | Іске асырылуы |
|---|---|
| Тапсырма мазмұнды | Әр карточка нақты тарихи фактілерге негізделген; тұзақтар тарихи білімді талап етеді (1721, 1918, 1940 ж., Қазақ КСР) |
| Әр жауап тексеріледі | 4 кезеңнің бәрі автоматты бағаланады (`ScoreCalculator`) |
| Қате жауапқа нақты түсіндірме | Әр маңызды сөйлемде `note`, әр хронология элементінде `explain`/`anomaly_note`, әр карточкада `reliability_explain`, әр қорытынды нұсқасында `feedback` |
| «Біржақты ≠ жалған» | Ресми рапорт пен ТАСС-тан да құнды фактілер алынады (жасыл белгілер) |
| «Скептицизм ≠ релятивизм» | «Ештеңе білуге болмайды» деген нұсқа әдейі қате деп бағаланады (1-, 3-іс) |
| Асығыстық марапатталмайды | Уақыт бонусы тек дәлелділік ≥ 70 болғанда беріледі |
| Кеңес — оқу құралы | Әр кезеңде 3 деңгейлі кеңес (бағыт → нақтылау → шешімге жақын), айыппұлы шағын |

### 5.3. Сабақта қолдану сценарийі (45 мин)
5 мин — кіріспе («фейк тарихи пост» мысалы) · 30 мин — жұппен 2–3 іс · 7 мин — аналитика экранын талқылау («Қай дағды әлсіз? Неге?») · 3 мин — рефлексия.

## БЕТ 6. Статистика, екі параметрді салыстыру және бейімделу

### 6.1. Жиналатын статистика (`Stats` → `GameState` → `user://history_detective_save.json`)
Қателер саны (жалпы және кезең бойынша), хронология ауытқуы (Σ|позиция айырмасы|), хронология қатесі
(орнында емес элементтер), сәйкессіздіктер (табылған/байқалмаған/қате), сенімділік дәлдігі (шкала және белгі),
дәлелділік баллы (0–100), эпизод уақыты және кезеңдер уақыты, кеңестер саны (кезең бойынша), салыстыру режимін қолдану.

### 6.2. Нормаланған метрикалар
| Метрика | Формула |
|---|---|
| Хронология қатесінің үлесі (CE) | орнында емес элементтер / барлық элемент |
| Сенімділік бағалау дәлдігі (RA) | 0.6 × орташа(1 − |Δшкала|/4) + 0.4 × дұрыс белгі үлесі |
| Уақыт қатынасы (TR) | эпизод уақыты / мақсатты уақыт |
| Қорытынды сапасы (Q) | дәлелділік баллы / 100 |
Профиль соңғы іске 0.6, алдыңғылардың орташасына 0.4 салмақпен есептеледі (бір кездейсоқ нәтиже профильді бұзбайды).

### 6.3. Салыстыру A: Хронология қатесі ↔ Сенімділік дәлдігі
| Жағдай | Диагноз | Бейімделу шешімі |
|---|---|---|
| CE > 30 % және RA ≥ 75 % | Уақыт осі әлсіз | Карточкада уақыт маркерлері ⏱ көкпен ерекшеленеді; жасырын даталарға «Бағдар» шығады |
| CE ≤ 30 % және RA < 60 % | Дереккөз талдауы әлсіз | Сенімділік кезеңінде «автор мүддесі / жанр / уақыт арақашықтығы» салыстыру кестесі |
| CE > 30 % және RA < 60 % | Екеуі де әлсіз | Екі көмекші + хронологияның 1-ші және соңғы элементі бекітіледі + кеңес деңгейі +1 |
| CE ≤ 30 % және RA ≥ 75 % | Сарапшы | Кеңес деңгейі −1, ұпай коэффициенті +10 % |
| Аралық | Теңгерімді | Өзгеріссіз |

### 6.4. Салыстыру B: Эпизод уақыты ↔ Қорытынды сапасы
| Жағдай | Диагноз | Бейімделу шешімі |
|---|---|---|
| TR < 0.6 және Q < 50 % | Импульсивті | Келесі істе «Салыстыру» режимін қолданбай зерттеуді аяқтау мүмкін емес |
| TR > 1.3 және Q ≥ 70 % | Мұқият | Мақсатты уақыт ×1.2 (баяу, бірақ сапалы жұмыс айыппұлсыз) |
| TR > 1.3 және Q < 50 % | Қиналып жүр | Кеңес деңгейі +1, хронология анкерлері, кезең бағдары автоматты көрсетіледі |
| TR ≤ 1.0 және Q ≥ 70 % | Еркін меңгерген | Мақсатты уақыт ×0.9, ұпай коэффициенті +5 % |
| Қалғаны | Қалыпты | Өзгеріссіз |

**Кеңес деңгейі (0–3)** әсері: қолжетімді кеңестер саны = min(3, 1 + деңгей), айыппұл = max(10, 25 − 5×деңгей),
деңгей ≥ 2 болса — әр кезеңде әдістемелік «Бағдар» автоматты көрінеді.
Аналитика экранында нақты сандар, шектер және шешімнің мәтіндік негіздемесі (A, B, нәтиже) көрсетіледі.

## БЕТ 7. Техникалық архитектура, тәуекелдер, даму жоспары

### 7.1. Архитектура
| Қабат | Модуль | Жауапкершілігі |
|---|---|---|
| Деректер | `data/episodes.json`, `DataRepo` | Мазмұн кодтан бөлек; жаңа іс = JSON өңдеу |
| Логика | `score_calculator.gd`, `adaptive_engine.gd` | Static, сахнасыз; `tests/test_logic.gd` арқылы тестіленеді |
| Күй | `GameState`, `Stats` | Прогресс, құлыптар, тарих, профиль, JSON сақтау/экспорт; ағымдағы эпизод статистикасы |
| Көрініс | `ui_kit.gd`, `overlay.gd`, 5 компонент, 5 сахна | UI кодпен құрылады (сахна файлдары минималды) — нұсқаларды біріктіру (merge) жеңіл |

Деректер ағыны: `investigation.gd` → `ScoreCalculator` (тексеру) → `Stats.record_*` → `Stats.finish_episode()` →
`GameState.commit_record()` → `AdaptiveEngine.profile_from_history()` → `user://…save.json` → келесі істің `begin_episode(profile)`.

### 7.2. Тәуекелдер және шешімдер
| Тәуекел | Шешім |
|---|---|
| Тарихи дәлдік | Тек жалпыға танылған фактілер; даулы даталар «шартты» деп белгіленген; карточкалар «модельдік үзінді» деп ашық көрсетілген |
| Сезімтал тақырып (1916, 1986) | Бейтарап академиялық тіл; ресми бағаның қайта қаралғаны құжатталған фактімен (1989–1990 комиссия) негізделген |
| «Бәрін белгілеу», кездейсоқ реттеу | Нормаланған айыппұл (бәрін белгілеу = 0), хронологияның нөлдік нүктесі — кездейсоқ ретсіздік |
| Шрифт глифтері | Жүйелік fallback + `assets/fonts/main.ttf` арқылы ауыстыру |

### 7.3. Даму жоспары
v1.1 — сүйреп-тастау (drag & drop) хронологиясы, дыбыс/музыка; v1.2 — мұғалім панелі (сыныптың JSON есептерін біріктіру);
