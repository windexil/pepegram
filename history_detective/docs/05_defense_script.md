# Комиссия алдындағы қорғау сценарийі
## History Detective — Тарихи дерек зерттеушісі (КЕЙС 07)

Құрылымы: **А) ойын демонстрациясы 5–7 мин** → **Б) жобалық шешімдер мен сұрақтар 3–5 мин**.

### Дайындық (қорғаудан 10 минут бұрын)
1. Жобаны Godot-та ашып, **F5** арқылы бір рет іске қосыңыз (импорт аяқталсын).
2. Демо үшін **екі күй** дайындаңыз:
   - «Таза» күй: Басты мәзір → Прогресті тазалау (1-істі нөлден көрсету үшін).
   - «Толық» күй: алдын ала 3 іс өтілген `history_detective_save.json` көшірмесі (аналитика мен 3-істі бірден көрсету үшін). Файл орны: `user://` (README 4-бөлім).
3. Экранды 1280×720 немесе толық экранға қойыңыз, дыбысты өшіріңіз.
4. Резерв: ойынның қысқа бейнежазбасы (2 мин) — техникалық ақау болса.

## Б. Жобалық шешімдерді түсіндіру (3–4 мин)

1. **Неге тест емес, тергеу?** (30 с) — Тест фактіні тексереді, ал біз *әдісті* жаттықтырамыз: sourcing → contextualization → corroboration. Әр кезең бір дағдыға сәйкес.
2. **Күрделілік қалай өседі?** (30 с) — Ашық анахронизм → шындық пен өтірік араласқан біржақтылық пен жад қатесі → жанама уақыт маркерлері мен нәзік атау қатесі; жасырын даталар 0 → 4 → 5.
3. **Ұпай экономикасы** (40 с) — 100/300/300/300 + бонус. Ең қымбат қате — жалған дерекке сүйенген қорытынды. «Бәрін белгілеу» мен кездейсоқ хронология эксплойттары формула деңгейінде жабылған. Уақыт бонусы тек дәлелді қорытындыға.
4. **Бейімделу** (50 с) — Екі жұп параметр, нақты шектер (30 %, 60/75 %, 0.6/1.3, 50/70 %), салмақталған тарих (0.6/0.4). Шешімдер: уақыт маркерлері, салыстыру кестесі, анкер элементтер, міндетті салыстыру, уақытты ұзарту/қысқарту, кеңес деңгейі 0–3. Әр шешімнің мәтіндік негіздемесі экранда.
5. **Техника** (40 с) — Godot 4.3 + GDScript; мазмұн JSON-да; логика static модульдерде және headless тесттермен тексеріледі; күй autoload-та; UI кодпен құрылады. Жаңа іс — тек JSON.

## Ықтимал сұрақтар және жауап тіректері

| Сұрақ | Жауап тірегі |
|---|---|
| Дереккөздер шынайы ма? | Оқиғалар мен фактілер — шынайы әрі жалпыға танылған; карточкалар — оқу мақсатындағы **модельдік үзінділер** (Дулатидің «870 жылы» сөйлемі және ТАСС хабарламасының мазмұны — мағыналық аударма). Жалған құжаттар әдейі жасалған және ойында ашық белгіленген. |
| Неге 1916 және 1986 сияқты сезімтал тақырыптар? | Дәл осы тақырыптар бойынша желіде фейк көп таралады; ойын бір «дұрыс идеологияны» емес, **дәлелмен** бағалау әдісін үйретеді. 1986 жылғы ресми баға 1989–1990 жж. комиссия қорытындысымен қайта қаралғаны — құжатталған факт. |
| Сенімділіктің «дұрыс» бағасы субъективті емес пе? | Сондықтан шкала жақындығы бойынша бағаланады (±1 айырма шкала ұпайының 75 %-ын береді), ал 2-істегі пост үшін екі белгі де (манипуляция/анахронизм) қабылданады. Әр бағаның сарапшылық негіздемесі көрсетіледі. |
| Бейімделу қаншалықты сенімді, бір нәтижеден қорытынды жасамай ма? | Метрикалар салмақталады: соңғы іс 0.6, алдыңғылар 0.4. Шектер аралық аймақпен бөлінген (60–75 %), «теңгерімді» профиль өзгеріс жасамайды. |
| Оқушы кеңеспен ғана өтіп кете ала ма? | Кеңес саны шектеулі (1–3), әрқайсысы ұпай алады; соңғы кеңес те жауапты толық айтпайды — дәлелдерді таңдау бәрібір ойыншыда. |
| Мұғалім нәтижені қалай көреді? | Аналитика экраны + JSON экспорт: уақыт, қателер, хронология ауытқуы, сенімділік дәлдігі, дәлелділік, кеңестер, бейімделу профилі. Даму жоспарында — сынып бойынша біріктіретін мұғалім панелі. |
| Неге drag & drop емес, ▲/▼? | Прототипте сенімділік пен қолжетімділік басым: ▲/▼ тінтуірмен де, сенсорлы экранда да қатесіз жұмыс істейді. Drag & drop — v1.1 жоспарында. |
| Плейтест нәтижесі қандай? | Плейтест хаттамасы мен түзетулер журналы `docs/03_playtest_report.md`-де; негізгі түзетулер: белгілер эксплойтын жабу, бейтарап сөйлемдер, кездейсоқ хронологияның нөлдік нүктесі, уақыт бонусының шарты. |
| Ойынды қалай кеңейтуге болады? | `episodes.json`-ға жаңа эпизод нысанын қосу жеткілікті; тесттер деректер тұтастығын тексереді. Жоспарда: Алаш, Жібек жолы, Тәуелсіздік; орыс/ағылшын тілдері. |
