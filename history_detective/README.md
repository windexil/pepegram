# History Detective — Тарихи дерек зерттеушісі

**КЕЙС 07** · Бағыты: Тарих және медиасауаттылық · Автор/орындаушы: **Абылла Аяжан Қайратқызы**
Қозғалтқыш: **Godot 4.3+** · Тіл: **GDScript** · Интерфейс тілі: қазақ тілі

Ойыншы — тарихи дерек детективі. Әр істе ол 3 дереккөз карточкасын зерттейді, қатар салыстырады,
оқиғалар мен дереккөздерден хронология құрады, уақыттық сәйкессіздіктерді (анахронизмдерді) табады,
әр дереккөздің сенімділігін бағалайды және тек сенімді дәлелдерге сүйеніп қорытынды жасайды.
Жүйе әр жауапты тексеріп, педагогикалық түсіндірме береді, статистиканы `user://` ішіне JSON
түрінде сақтайды және екі параметрді салыстыру арқылы келесі істің қиындығын/кеңес деңгейін бейімдейді.

## 2. Ашу, баптау, іске қосу

1. **Godot 4.3** (немесе жаңарақ 4.x, *Standard* нұсқасы, .NET қажет емес) жүктеңіз: <https://godotengine.org/download>.
2. Godot → **Project Manager** → **Import** → `history_detective/project.godot` файлын таңдаңыз → **Import & Edit**.
3. Алғашқы ашылуда редактор ресурстарды импорттайды (бірнеше секунд).
4. **F5** (Run Project) — `main_menu.tscn` басты сахна ретінде іске қосылады.
5. Тексеру: **Project → Project Settings → Globals/Autoload** бөлімінде `DataRepo`, `GameState`, `Stats` тұруы керек (project.godot-та алдын ала бапталған).

**Қаріп (шрифт).** Godot 4-тің кірістірілген шрифті кириллицаны қолдайды, ал жетіспейтін глифтер жүйелік шрифттен алынады.
Егер қазақ әріптері (ә, ғ, қ, ң, ө, ұ, ү, һ, і) немесе ★ ⏱ ▲ белгілері дұрыс көрінбесе, кез келген
Unicode шрифтін (мысалы, *Noto Sans* / *PT Sans*) `res://assets/fonts/main.ttf` деп салыңыз — `UIKit.build_theme()` оны автоматты қолданады.

**Экспорт (міндетті емес):** Project → Export → Windows Desktop / Linux / Web → шаблондарды жүктеп, Export Project.

**Тесттер (headless):**
```bash
cd history_detective
godot --headless --path . -s res://tests/test_logic.gd     # шығу коды 0 = барлығы өтті
```

## 3. Ойын циклі (Core Loop)

```
Іс таңдау → Брифинг (зерттеу сұрағы + бейімделу баптаулары)
   → 1. Зерттеу: 3 карточка, деректемелер, сөйлемдерді белгілеу, «Салыстыру» режимі
   → 2. Хронология: ▲/▼ реттеу + ⚠ уақыттық сәйкессіздік → тексеру + түсіндірме (3 әрекетке дейін)
   → 3. Сенімділік: 1–5 шкала + бұрмалану түрі → тексеру + сарапшы түсіндірмесі
   → 4. Қорытынды: нұсқа + дәлелдер → дәлелділік тексерісі
   → Нәтиже: ұпай құрылымы, жұлдыздар, өту шарты, бейімделу шешімі
   → Аналитика / Келесі іс / Қайта ойнау
```

Өту шарты: қорытынды дұрыс **және** нәтиже ≥ 45 %. Үш іс шешілсе — «Бас детектив» (ойынның жеңіс шарты).

## 4. Сақталатын деректер

| Файл | Мазмұны |
|---|---|
| `user://history_detective_save.json` | прогресс (ашылған/шешілген істер, үздік нәтижелер), барлық әрекеттер тарихы, бейімделу профилі |
| `user://history_detective_report.json` | аналитика экранындағы «JSON есепті экспорттау» батырмасы — мұғалімге беруге арналған есеп |

`user://` орны: Windows — `%APPDATA%\Godot\app_userdata\History Detective — ...\`, Linux — `~/.local/share/godot/app_userdata/...`.
Әр әрекет жазбасының өрістері: `time_sec`, `target_time_sec`, `clue_found/false/total`, `chrono_errors`,
`chrono_deviation`, `chrono_attempts`, `anomaly_hits/missed/false`, `reliability_accuracy` (+ шкала/белгі бөлек),
`reliability_errors`, `conclusion_correct`, `evidence_score`, `forbidden_used`, `hints_used`, `hints_by_stage`,
`stage_times`, `parts`, `score`, `max_score`, `percent`, `stars`, `total_errors`, `passed`, `profile_used`.

## 5. Мазмұнды кеңейту

`data/episodes.json` ішіндегі эпизод нысанын көшіріп, `id`/`index`-ті өзгертіңіз. Әр карточкада
`fragments` — сөйлемдер тізімі: `clue: true` + `kind: "green"|"red"` + `note` (маңызды белгі), `tm: true` (уақыт маркері).
Хронология элементтері **дұрыс ретпен** жазылады (ойын өзі араластырады). `anomaly: true` — уақыттық сәйкессіздік.
Тесттер (`tests/test_logic.gd`) деректер тұтастығын автоматты тексереді.
